
# ElectroPOS

ElectroPOS es un sistema de punto de venta (POS) desarrollado en PHP con base de datos MySQL. Está diseñado para facilitar la gestión de productos, clientes y facturación en pequeñas y medianas empresas.

## 🌐 En línea

Puedes ver la aplicación funcionando en el siguiente enlace:  
[http://electropos.ct.ws/](http://electropos.ct.ws/)

## 🛠️ Características principales

- Registro y gestión de productos con stock
- Administración de clientes con historial de compras
- Generación de facturas con cálculo automático de totales
- Registro de ventas y consultas por fecha
- Reporte básico de transacciones
- Interfaz web simple y responsiva basada en Bootstrap
- Arquitectura basada en el patrón MVC para facilitar el mantenimiento

## 📦 Requisitos

- PHP 7.4 o superior
- MySQL o MariaDB
- Servidor web Apache (XAMPP, LAMP, etc.)

## 🚀 Instalación

1. Clona el repositorio o descarga el código.
2. Copia el contenido en la carpeta `htdocs` o el directorio raíz de tu servidor.
3. Importa el archivo `electropos.sql` en tu gestor de base de datos.
4. Configura la conexión a la base de datos en `config/database.php`.
5. Abre el navegador y accede a `http://localhost/` o la URL configurada.
